# API Design Standards

- **Error format**: `{"error": {"code": "...", "message": "..."}}` on every non-2xx response (`internal/httpserver/respond.Error`). Not RFC 7807 — kept as a simpler flat envelope for this template. Known codes: `validation_error`, `unauthorized`, `not_found`, `internal_error`, `rate_limited`.
- **Pagination**: `?page=&page_size=` on `GET /api/v1/articles`, capped at `page_size<=100` (`internal/articles/handler.go`); response includes `total`/`page`/`page_size`.
- **Rate limiting**: Redis-backed fixed-window counter (`internal/httpserver/middleware/ratelimit.go`), implemented as a single atomic Lua script (INCR + conditional EXPIRE) to avoid a key ending up with no TTL if the process dies between the two calls. IP-keyed on `/api/v1/auth/register` and `/api/v1/auth/login` (10 req/min); user-keyed (post-auth) on article writes — create/update/delete/publish (30 req/min). **Fails open**: if Redis is unreachable, the middleware logs the error at `Error` level and allows the request through rather than blocking it — rate limiting is treated as an abuse-prevention nice-to-have, not a hard dependency the whole auth/write surface should go down with.
- **Idempotency**: not implemented in this version — flagged here as a gap, not falsely claimed as done. There is no idempotency-key mechanism on any write endpoint.
- **CORS**: not implemented in this version — no CORS middleware exists in the codebase today. Add one to `internal/httpserver/router.go` if the API is to be consumed from a browser on a different origin.
- **Auth**: `Authorization: Bearer <access_token>`; obtain via `POST /api/v1/auth/register` or `POST /api/v1/auth/login`, refresh via `POST /api/v1/auth/refresh` (rotates the refresh token — the old one is invalidated on use).
- **API docs**: generated by swaggo/swag from handler annotations, served as Swagger UI at `/api/docs`. `/health/live` and `/health/ready` are deliberately excluded from the generated spec — they're unversioned infra probes mounted outside `/api/v1`, and annotating them would make Swagger UI advertise `/api/v1/health/...` URLs the server doesn't actually serve.
